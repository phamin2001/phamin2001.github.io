Privacy policy

Signal to Post · Last updated October 1, 2026

Signal to Post is a personal automation used only by its owner, with the owner's own Google account. It is not available to other users.

Google account data it uses

When the owner signs in with Google, the app's workflow tool requests Gmail access. Signal to Post uses that access only to:

  • search the owner's Gmail drafts to check whether today's draft already exists, so it does not create a duplicate; and
  • create one new draft in the owner's own Gmail account, containing the prepared post and an image.

It does not read the content of other emails, send email, delete anything, or change labels or settings.

Storage and sharing

  • Google sign-in tokens are stored only on the owner's own computer, inside the local workflow tool.
  • Gmail data is not copied to any server, sold, shared with third parties, or used for advertising or AI model training.
  • The news research uses public web sources only and does not involve Gmail data.

Removing access

Access can be revoked at any time from the Google Account page under Third-party apps and services.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
